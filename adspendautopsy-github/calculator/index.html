How to download each file (Google Ads, GA4, Meta)

Performance report — Google Ads

  • Click the Campaigns icon → Campaigns. Open the columns icon → Modify columns and make sure Cost, Conversions and Conv. value are shown, then apply.
  • Set a 30–90 day range, click the download icon (top right) → .csv.

Performance report — Meta Ads (if you run Meta)

  • Ads Manager → Campaigns. Customise columns so Amount spent, Purchases and Purchases conversion value are included, then apply.
  • Use Reports → Export table data → CSV.

True revenue — GA4

  • Reports → Acquisition → Traffic acquisition. Change the primary dimension to Session campaign (or Session Google Ads campaign for paid Google only) — the table already shows Total revenue.
  • Match the date range to your ad report, then Share this report → Download file → CSV. GA4 adds a few header rows above the table; the tool skips them.
  • No revenue showing? Your purchase/ecommerce events need to be set up in GA4 first — without them there's no revenue to export.

Bulksheet — Google Ads Editor (optional)

  • Google Ads Editor → Account menu → Export → Export whole account → CSV. Turn on "Include original columns in CSV/ZIP exports" in Settings to keep performance data.

Files are matched by campaign name, so the names need to line up across files — your Google Ads campaign name should match GA4's Session Google Ads campaign, and a Meta campaign matches GA4's Session campaign via your UTM. Paths follow the current interfaces; if something's moved, search the platform's own help.

Can't get the revenue to line up?

This only stitches if your campaign names match across Google Ads, GA4 and Meta — and in real accounts they often don't: UTMs, renames, and inconsistent naming leave your revenue stranded from your spend. Mapping it back to the right campaigns is fiddly, one-off work.

Profit per saleprice × margin − your CPA. Break-even ROAS = price ÷ (price × margin).

Revenue gapWhen both analytics and ad-platform revenue are present, shows how far the platform over- or under-reports — the attribution gap behind an inflated ROAS.
